# 30_stepper_5motor_magnet_test：树莓派视觉拼图执行器

本工程是E题三种网页任务共用的天猛星执行端，不再是六键长距离测试程序。

- `KEY1 / PB17`：请求“小问1”，把下半区4片全部搬到上半区。
- `KEY2 / PB18`：请求“小问2”，在上半区拼成题图2的 `100 mm × 60 mm` 矩形。
- 网页模式3：接收1～4片未知白片计划，在上半区重建矩形。
- `PB21`：急停，先立即关闭电磁铁，再停止1～5号电机。

KEY1、KEY2只向树莓派请求方案，不直接驱动电机。模式1/2必须稳定识别到4片；模式3允许1～4片。所有模式都必须锁定A4物理方向并验证全部坐标可达，MCU收到完整计划和`COMMIT`后才运动。

## 坐标与固定初始位置

A4物理左上角为 `(0,0)`，X向右、Y向下，单位mm。每次上电/复位前必须人工确认：

- 电磁铁中心位于A4坐标 `(5.0, 61.0) mm`；
- Z轴位于上方初始安全高度；
- 5号旋转轴为0度；
- 电磁铁关闭。

没有原点或限位开关，复位时程序只按上述位置建立开环坐标。急停、驱动断电或卡住后坐标不再可信，必须人工回到固定初始位置再复位。

机械可达范围固定为：

- `X = 5.0 .. 205.0 mm`
- `Y = 61.0 .. 286.0 mm`

当前实物方向：1号电机正转向左，因此A4的X正向命令会让1号电机反转；2、3号电机同方向同步控制Y；4号正转向上；5号负责铁片旋转。

## 接线

### 树莓派 ↔ 天猛星 UART3

| Raspberry Pi | 天猛星 MSPM0G3507 |
|---|---|
| GPIO14 / TXD，物理8脚 | PB13 / UART3 RX |
| GPIO15 / RXD，物理10脚 | PB12 / UART3 TX |
| GND，物理6脚 | GND |

两块板分别供电，只交叉连接TX/RX并共地；不要连接双方5V，也不需要连接双方3.3V。UART为115200、8N1。

### 五台步进驱动器

- PA10 / UART0 TX 并接五台Emm驱动器RX；驱动器地址为1～5。
- 当前程序不读取驱动器回复，驱动器TX不要并接PA11。
- 天猛星与驱动器通信地必须共地，电机动力电源独立供电。

### 电磁铁

- PA14连接MOS模块`SIG/IN`，控制电磁铁。
- 天猛星GND、MOS控制GND、电磁铁电源负极共地。
- 电磁铁必须独立供电；若模块无续流保护，在负载两端反向并联续流二极管。

## 每片自动动作

每片依次执行：

1. 在安全高度移动到识别出的铁片质心；
2. 4号轴负向下降8mm；
3. 开启电磁铁并等待400ms；
4. 4号轴正向抬升8mm；
5. 在安全高度同时启动5号轴旋转和XY目标移动；
6. 等待XY和旋转中较慢的一项完成并停稳；
7. 下降8mm，关闭电磁铁并等待400ms；
8. 抬升8mm，5号轴反转回零；
9. 全部计划片完成后XY返回固定HOME。

模式1优先不旋转；由于上半区可用高度较窄，必要时视觉规划会让个别长片旋转`±90°`后无重叠排布。模式2按题图2计算每片质心和角度。

## 烧录与启动顺序

1. 在CCS中刷新工程，构建并烧录`30_stepper_5motor_magnet_test`。
2. 人工把滑台放回固定HOME，确认Z安全、旋转轴0度、磁铁关闭，再复位天猛星。
3. 树莓派执行：

   ```bash
   cd /home/wxm/28_puzzle_vision/raspberry_pi
   sh start_puzzle_vision.sh
   ```

4. 打开 `http://10.29.23.60:8081/`。模式1/2只有“A4方向锁定、4片稳定、方案可执行、MCU串口已连接”都正常时才按KEY1或KEY2；模式3使用网页一键启动并由树莓派自动等待稳定方案。

## 首次联调必须先确认

- 5号轴`+90°`从相机俯视是否为顺时针。若相反，只修改树莓派启动参数`--rotation-sign -1`，不要在MCU再反一次。
- `STEPPER_MOTOR_5_PULSES_PER_OUTPUT_REV`是否确实对应末端360°。
- 4号轴负向0.8cm确实下降，正向0.8cm确实回到原安全高度。
- 第一次不要放铁片，只观察四轴路线，手放在PB21急停旁。确认路线无误后再做带铁片测试。

驱动器TX未回接MCU，完成状态由距离和转速保守计时，不能证明机构没有卡住。全过程必须有人看护。

串口命令和状态格式见 [RASPBERRY_PI_PROTOCOL.md](RASPBERRY_PI_PROTOCOL.md)。

## 模式3可变片数计划

网页的第二大问第（1）小问使用模式3。固件接受 `PLAN request_id 3 item_count`，其中 `item_count=1..4`；收齐对应 `ITEM` 并收到 `COMMIT` 后才执行。0片、5片、重复ITEM、缺失ITEM、越界坐标均会被拒绝。

当前并行动作版本的 READY 标识为 `GANTRY_V3_XY_ROTATE`。铁片抬到安全高度后，XY移动和5号轴旋转同时开始；只有两者的保守完成时间都到达后，Z轴才会下降。

LED状态：执行中常亮，完成后慢闪5秒，视觉/计划拒绝中速闪4秒，运动故障快闪，PB21急停超快闪。
