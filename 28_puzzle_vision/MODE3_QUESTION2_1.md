# 模式3：第二大问第（1）小问

模式3用于识别纵向 A4 下半区随机摆放的1～4片未知白色碎片，自动重建题目规定尺寸的矩形，并搬运到分界线上半区。原模式1、模式2和物理按键功能不变；模式3通过网页“一键启动：识别、解算并自动拼图”执行。

当前取放方向是针对本机滑台行程确定的：

- `MODE3 PICK ZONE (A4 LOWER)`：分界线下方识别和吸取白片；
- `MODE3 PLACE ZONE (A4 UPPER)`：分界线上方重建矩形；
- 目标矩形沿分界线方向水平居中，优先将小片放在分界线附近、大片放在更靠上的一侧，使所有放置质心尽量可达。

## 一键启动

1. 将电磁铁中心放在固定 HOME：A4 坐标 `(5,61) mm`；Z 位于安全高度，5号轴为0°，电磁铁关闭。
2. 烧录 `30_stepper_5motor_magnet_test`，给电机与电磁铁驱动上电，再复位天猛星。
3. 启动树莓派服务：

   ```bash
   cd /home/wxm/28_puzzle_vision/raspberry_pi
   sh stop_puzzle_vision.sh
   sh start_puzzle_vision.sh
   ```

4. 浏览器打开 `http://10.29.23.60:8081/`。
5. 点击“一键启动：识别、解算并自动拼图”。程序会自动等待 A4 和白片连续多帧稳定、求解出合法矩形、确认串口和全部坐标可达，再启动电机；不需要二次确认。

当前机械质心可达范围是 `X=5..205 mm, Y=61..286 mm`。任一吸取点或放置点不可达时会整套拒绝，不会只执行一部分。相机/A4位置固定时，服务重启会加载保存的A4标定；相机或A4移动后必须重新标定。

## 识别与重建

网页和 `/api/status` 显示：

- 1～4片源轮廓、面积、边长、角度、质心和安全吸取点；
- 自动重建矩形、每片目标轮廓、放置点与最短旋转角；
- 片间间隙、对应顶点距离、解的几何评分和可达性；
- 冻结后的动作顺序及预计总时间。

求解器只允许平面旋转和平移，不做镜像或翻面。它根据候选拼接边、外边界约束、矩形尺寸、重叠面积、缺口和顶点误差进行组合搜索。检测器还会把两套白片轮廓结果进行交叉补全，减少小片因曝光或边界阈值变化而漏检。

默认保留机械安全缝，并把最大对应顶点距离控制在题目上限以内。出现轮廓质量不足、多解歧义、目标尺寸非法、碎片相交、点不可达或预计超时时均保持不动并显示原因。

目标矩形默认中心 X 为 A4 中线 `105 mm`。如果实物电磁铁中心相对视觉放置点存在固定误差，可在网页填写“模式3放置X补偿”和“模式3放置Y补偿”；补偿只作用于电机放置坐标，不改变画出的理想矩形。

## 串口协议

模式3使用可变片数协议：

```text
PLAN request_id 3 item_count
ITEM request_id index pick_x10 pick_y10 place_x10 place_y10 angle_mdeg
COMMIT request_id
```

`item_count` 必须为1～4。固件拒绝0片、5片、重复ITEM、缺失ITEM、越界坐标及非法角度。第一片运动后，MCU只执行已冻结计划，后续画面变化不会修改任务。

## 执行动作

每片在安全高度移动到吸取点，下降8 mm吸起并抬升；随后 XY 向目标点移动，同时5号轴旋转到目标角度。固件等待两者中较慢的一项结束并留出停稳余量后才允许 Z 下降放片。放片后 Z 抬升、5号轴回零，再处理下一片；全部完成后 XY 返回固定 HOME。

READY 标识为 `GANTRY_V3_XY_ROTATE`。由于五台驱动器 TX 未回接 MCU，到位由距离、速度和加速度公式计时，并非编码器到位确认，测试时必须有人看护急停。
