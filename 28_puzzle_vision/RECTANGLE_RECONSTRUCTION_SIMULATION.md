# 未知矩形碎片重建仿真

这个仿真严格覆盖现场约束：碎片数为 1～4，每片 3～5 条边，每条物理边不短于 20 mm，每片至少有一条边属于目标矩形外轮廓，目标矩形长边 90～120 mm、短边 50～90 mm。

## 运行

在 `raspberry_pi` 目录执行：

```bash
python simulate_rectangle_reconstruction.py --pieces 4 --seed 2026 --template slanted
```

默认输出：

- `simulation_output/rectangle_reconstruction.svg`：真值切分、乱序输入和求解结果的三栏对照图；
- `simulation_output/rectangle_reconstruction.json`：生成参数、输入轮廓、求解位姿、约束检查和误差指标。

压力测试时可以给每个轮廓顶点加入独立高斯误差：

```bash
python simulate_rectangle_reconstruction.py --pieces 4 --seed 2026 --noise-mm 0.3
```

噪声使接缝端点和外轮廓不再严格一致；超过当前几何容差时，求解器会返回拒绝原因而不会输出一个勉强的错误动作。正式视觉链路应先做像素轮廓拟合、共线顶点合并和 A4 单应性标定，再把毫米坐标送入求解器。

纯几何验算默认不留缝。若要模拟机械放置间隙，可加 `--seam-gap-mm 4`；此时输出外包框会比原矩形略大，评价中的尺寸差也会包含该间隙。

## 求解算法

1. 对相机提取的每个多边形统一为逆时针顶点序列，检查片数、边数和最短边。
2. 枚举不同碎片的边对；当两条边长度接近时，只用旋转和平移把它们反向重合，不允许镜像和缩放。
3. 深度优先搜索连接 1～4 片，得到候选邻接图；对 T 形接缝另做“短边匹配长边子段”的回退搜索。
4. 将每个候选沿某条边旋正，检查目标长短边范围、碎片总面积/外包矩形面积、每片是否贡献外轮廓边以及碎片是否重叠。
5. 在候选的未知尺寸外包框内按 1 mm/像素栅格化，联合评价填充率、重叠像素、连通分量和外轮廓周长；这一步不写死 10×6 cm。
6. 对最佳邻接拓扑补齐 DFS 生成树遗漏的闭环接缝，再用最小二乘同时优化各片旋转和平移，把相机轮廓误差分摊到全图。
7. 若全局质量不合格、优化变差或不同邻接关系的前两名太接近，则拒绝输出，避免机械系统执行错误解。
8. 输出每片从观测姿态到目标姿态的旋转角和平移目标；实机模式再把整个矩形放入 A4 可达区域并规划抓放顺序。

该方法不依赖颜色、原始摆放位置或预先知道的矩形尺寸。真实系统只需把视觉模块得到的 `vertices_mm`、吸取点和片号传给 `reconstruct_rectangle()`。

四块矩形网格可能存在整行或整列互换后仍为同尺寸矩形的多解。仅凭无颜色轮廓无法恢复不可观测的“原片号顺序”，但这些解都能无重叠、满覆盖地完成矩形重建。因此 JSON 同时给出 `geometric_success` 和带片号的顶点误差，正式判定应以前者为准。

四片默认使用 `slanted`：一块大三角形的斜边与另外三片形成两个 T 形接点，接近现场参考图且所有边仍不短于 20 mm。使用 `--template grid` 可以切换回简单的 2×2 对照组。
改变 `--seed` 会同时改变目标尺寸、左边三个分段、主斜边接点、碎片散落顺序和各片旋转角，因此可以批量生成不同难例。

SVG 现在包含四栏：合法切分真值、乱序输入、带粉色候选匹配缝的优化前布局、全局评分和闭环优化后的最终布局。JSON 同时记录 `global_quality`、`pose_graph_optimization` 和 `matched_seams`，便于比赛报告引用。

## 回归测试

```bash
python -m unittest test_rectangle_reconstruction_simulation.py
```

测试会批量检查生成器的全部现场约束，并验证 1、2、3、4 片都能从随机旋转和平移后的轮廓恢复。
